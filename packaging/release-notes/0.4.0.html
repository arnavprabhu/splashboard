Splashboard 0.4.0

Splashboard now requires Splash 1.3.2. Update the engine with brew upgrade incoai/tap/splash, or from Settings → About.

  • The SSD cache is now on by default, as it is in Splash 1.3.2: it uses up to 32 GiB and follows your disk's free space, so follow-up turns start faster. Existing installs are moved to the new default once. To turn it off, set Settings → Cache → SSD cache to Off.
  • New settings: Thinking budget (caps how long a model thinks before it answers) and, under Advanced, state format (BF16 holds about twice as many cached conversations), the text that ends thinking at the budget, and a daily SSD write budget. Chat and profiles can also set a thinking budget for each request.
  • Release memory: free the model's weights now and keep the cache, from Status, the menu bar, or splash release-memory. The next request loads them again.
  • Status lists the requests running right now and how many cached tokens were shared between requests. Each Chat reply shows how many draft tokens were accepted.
  • More models load: GGUF UD-Q8_K_XL and other layouts, and NVFP4 and FP8 checkpoints, which Models now labels and finds in search.
  • The Codex CLI keeps your ChatGPT Apps connectors on, since Splash now accepts their tool names. Stop sequences now work with tools, and a reply limit longer than the context is shortened instead of refused.

Engine: Splash by inco.ai, 1.3.2 or newer (Homebrew incoai/tap/splash). Restart the server after upgrading Splash. Splashboard is not an inco.ai product.

Splashboard is not notarized. On a first install, open it once from System Settings → Privacy & Security → Open Anyway.
