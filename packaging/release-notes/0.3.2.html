Splashboard 0.3.2

  • Downloading a GGUF model from a repository that has only one GGUF file, such as Hcompany/Holo4-27B-GGUF, no longer fails after the download with "no single GGUF matches". The model is now installed under its repository's name, the ID Splash accepts for it.

Engine: Splash by inco.ai, 1.3.1 or newer (Homebrew incoai/tap/splash). Splashboard is not an inco.ai product.

Splashboard is not notarized. On a first install, open it once from System Settings → Privacy & Security → Open Anyway.
