Splashboard 0.3.0

Splashboard now requires Splash 1.3.1. Update the engine with brew upgrade incoai/tap/splash, or from Settings → About.

  • MLX models in more formats now show as compatible and download: affine 2, 3, 4, 5, 6 and 8 bits in groups of 32, 64 or 128, mixed precision, and mxfp4. A format Splash can't load still says why in plain words.
  • Splash packages (incoai/*-Splash) no longer load in Splash 1.3.1, so the catalog no longer lists them. An installed package shows "No longer loads" with the MLX model to download instead, and you can delete it.
  • GGUF repositories with an F16 vision projector, and MLX repositories that keep their image processor in processor_config.json, now count as vision capable.
  • Status shows your Mac's thermal state when it runs hot, since Splash slows down while the Mac cools.

Engine: Splash by inco.ai, 1.3.1 or newer (Homebrew incoai/tap/splash). Splash 1.3.1 doesn't reuse the conversation cache saved by 1.3.0; it fills again as you chat. Splashboard is not an inco.ai product.

Splashboard is not notarized. On a first install, open it once from System Settings → Privacy & Security → Open Anyway.
