Splashboard 0.2.0

  • First public release, under the name Splashboard.
  • A menu bar app and a web admin for the Splash engine: one address for the OpenAI- and Anthropic-compatible API, quick model switching, and live status.
  • A welcome wizard installs Homebrew and Splash, picks storage, and downloads a first model.
  • Model downloads check compatibility first, and resume after an interruption.
  • Chat with tools and MCP servers, plus a playground, a tokenizer, judgments and benchmarks.
  • splash launch starts Claude Code, Codex, OpenCode, Pi and Hermes against Splash for that session only. Claude Desktop and the Codex app connect and are always restored.
  • Updates arrive through Check for Updates… in the menu.

Engine: Splash by inco.ai, 1.3.0 or newer (Homebrew incoai/tap/splash). Splashboard is not an inco.ai product.

Splashboard is not notarized. On a first install, open it once from System Settings → Privacy & Security → Open Anyway.
