Splashboard 0.3.3

  • Connecting the Codex app no longer stops Codex from starting. Splash lists PDF input for vision models, and recent Codex versions refuse a model catalog that names it ("unknown variant `pdf`"); the catalog now lists only the input types Codex accepts.
  • Claude Desktop now shows which Splash model it is using: the deployment beside your account is named after it, such as "Splash · Holo4-27B-GGUF". Claude's model menu keeps Claude's own names (Fable, Opus, Sonnet, Haiku), since Claude names those models itself. The name is set when you connect, so reconnect after switching models to update it.

Engine: Splash by inco.ai, 1.3.1 or newer (Homebrew incoai/tap/splash). Splashboard is not an inco.ai product.

Splashboard is not notarized. On a first install, open it once from System Settings → Privacy & Security → Open Anyway.
