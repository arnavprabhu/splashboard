Splashboard 0.7.0

Splashboard now requires Splash 1.5.0. Update the engine with brew upgrade incoai/tap/splash, or from Settings → About.

  • Usage now records prompt and decode times for requests from Claude Code, Codex and other agents, not only for Chat Completions, so their speeds show up in Usage. Claude Code's prompt size now counts the cached part too.
  • Chat's reasoning effort list says what each effort does to the loaded model: which ones it tells apart, which ones render like another, and what the model default is.
  • Download progress follows Splash's own count while it fetches the smaller files, so it no longer sits at 0% and then jumps.
  • A paused download keeps its progress. Splash 1.5.0 cleans up interrupted downloads before each new one, and would otherwise have removed what a paused download had fetched.
  • splash doctor and Settings → About notice Splash's new desktop app and warn when it is on a different release from the Homebrew engine. The two share installed models, and switching between releases makes the engine rebuild them.
  • Extra engine flags must use full option names, as Splash 1.5.0 requires; an abbreviation is refused when you save.
  • Splash 1.5.0 brings faster decoding on M5 and M6 Macs, lower memory for MoE routers, and a fix for image requests that could crash a model streaming its experts from the SSD.
  • The first start of each GGUF model after the engine upgrade takes a little longer while Splash rebuilds its metadata. The SSD cache of GGUF and MLX MoE models starts empty once.

Engine: Splash by inco.ai, 1.5.0 or newer (Homebrew incoai/tap/splash). Restart the server after upgrading Splash. Splashboard is not an inco.ai product.

Splashboard is not notarized. On a first install, open it once from System Settings → Privacy & Security → Open Anyway.
