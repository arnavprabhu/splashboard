Splashboard 0.8.0

Splashboard now requires Splash 1.6.0. Update the engine with brew upgrade incoai/tap/splash, or from Settings → About.

  • Model checks, the variant table and local GGUF files work with Splash 1.6.0, which changed how it reads and selects GGUF files.
  • A split GGUF whose parts sit at the top of a repository is now one variant you can download. A variant kept in its own folder is no longer hidden by a file beside it whose name only ends in the variant.
  • Status shows more of what Splash 1.6.0 does with memory: how large the store of streamed experts is and how often it gave memory back, how many requests are waiting for memory, and where the time to a first token went.
  • Downloads say more clearly why they failed: a gated repository, no connection, or a repository Hugging Face does not have. Free disk space is counted the way Finder counts it, so a download is no longer refused while macOS can still make room.
  • Chat explains two new refusals: a request Splash will not run again because it was running both times the engine just failed, and PDFs that cannot be read.
  • POST /v1/chat/completions/count_tokens is available on Splashboard's port: it counts a Chat request's tokens without running it.
  • Splash 1.6.0 fixes long stalls when serving under a memory limit, restarts a failed engine more patiently, and renders PDFs in a sandbox.
  • The first start of each GGUF model after the engine upgrade takes a little longer while Splash rebuilds its metadata, and that model's persistent cache starts fresh once.

Engine: Splash by inco.ai, 1.6.0 or newer (Homebrew incoai/tap/splash). Restart the server after upgrading Splash. Splashboard is not an inco.ai product.

Splashboard is not notarized. On a first install, open it once from System Settings → Privacy & Security → Open Anyway.
