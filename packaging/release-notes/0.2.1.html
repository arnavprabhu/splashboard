Splashboard 0.2.1

  • Splashboard has an app icon: the red Splash "S", in Finder, the Dock and Launchpad.
  • Integrations now finds Claude Code, Codex, OpenCode, Hermes and Pi when they are installed in your home folder (such as ~/.local/bin). 0.2.0 listed them as not installed.
  • The Playground's first request no longer fails with "model not found" when the page opens before the model state arrives.
  • A request with an empty model name now goes to the loaded model instead of failing.
  • Pages no longer flash "Offline" and "No model loaded" while they load.

Engine: Splash by inco.ai, 1.3.0 or newer (Homebrew incoai/tap/splash). Splashboard is not an inco.ai product.

Splashboard is not notarized. On a first install, open it once from System Settings → Privacy & Security → Open Anyway.
