Splashboard 0.3.1

  • Starting a model now shows "Warming up" once its weights are loaded. Splash warms a model up before it serves, which can take a minute or more for a large model at a long context; that time used to show as "Loading weights", as if the start were stuck.

Engine: Splash by inco.ai, 1.3.1 or newer (Homebrew incoai/tap/splash). Splashboard is not an inco.ai product.

Splashboard is not notarized. On a first install, open it once from System Settings → Privacy & Security → Open Anyway.
