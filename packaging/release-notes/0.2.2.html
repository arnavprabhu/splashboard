Splashboard 0.2.2

  • Requests from the web admin's Playground, Chat, Judgments and Tokenizer now show in Usage history under their own names (such as splashboard-playground) instead of the browser's name.
  • Benchmark's Saved runs keep long model names on one line, shortened in the middle; hover for the full ID.
  • Screen readers hear dates, not "00:00:00", in Usage history's Tokens per day and Requests over time charts, and each model's own token count per day.
  • The Status page loads less code on first open.

Engine: Splash by inco.ai, 1.3.0 or newer (Homebrew incoai/tap/splash). Splashboard is not an inco.ai product.

Splashboard is not notarized. On a first install, open it once from System Settings → Privacy & Security → Open Anyway.
